# 领域文档

本文件规定工程类 Skill 如何读取本仓库的领域文档。

## 探索前读取

- 仓库根目录的 `CONTEXT.md`。
- 如果存在 `CONTEXT-MAP.md`，读取它以及与当前任务相关的上下文。
- `docs/adr/` 下与当前工作相关的 ADR。

如果这些文件不存在，静默继续。领域建模 Skill 会在术语或决策真正确定后按需创建，不要提前生成空文档。

## 文件结构

本仓库使用单上下文结构：

```
/
|-- CONTEXT.md
|-- docs/adr/
`-- src/
```

## 使用词汇表术语

Issue、提案、假设和测试名称必须使用 `CONTEXT.md` 定义的术语，不使用词汇表明确排除的同义词。

缺失概念可能意味着当前表述是临时造词，也可能代表真实领域缺口；使用 `/domain-modeling` 澄清后再记录。

## 标记 ADR 冲突

如果拟议工作与现有 ADR 冲突，必须明确指出冲突，不能静默覆盖原有决策。
