# 分流标签

相关 Skill 使用五种标准分流角色。本文件定义这些角色在仓库 Issue 跟踪系统中的标签映射。

| 标准角色 | 跟踪系统标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由 AFK Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 Skill 提到标准角色时，使用表中对应的跟踪系统标签。
